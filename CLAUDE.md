# Agent instructions

Read [AGENTS.md](AGENTS.md) for the current project instructions, latest checkpoint,
repository map and build/test policy. It is the shared source of truth for all
coding agents working on this repository.

Current player/developer documentation starts at [docs/README.md](docs/README.md),
with active work in [ROADMAP.md](ROADMAP.md). Historical session notes under
`.claude/` and dated review/checkpoint documents are evidence for older revisions,
not current instructions or acceptance results.

Builds and checks run locally. GitHub-hosted workflows are disabled and must not
be re-enabled or dispatched without a new maintainer request. Preserve original
recordings, release tags/packages and personal settings. Never run physical FFB
unattended. Public access is being prepared; do not change repository visibility
merely because documentation describes that preparation.
