# Cruis’n Collection v0.4.0 release candidate

Draft for review; not a published release. Attended gameplay and wheel acceptance
remain required by [the release checklist](../RELEASE-CHECKLIST.md).

- Improved widescreen seams and texture sampling, fine geometry and translucent
  shadows. Restored World transmission artwork through loading and Off Road's
  upper sky corners. Large startup framebuffer uploads now use masked GPU copies.
- Restored the V-Unit pause menu while emulation is stopped.
- Corrected reserved neutral force commands before amplification. Known obsolete
  input plugins are backed up during upgrade/first launch; unknown DLLs are preserved.
- Added actual driving input recording/replay, an external emulation clock,
  completed-frame captures and automated multi-game regression checks. Replays
  never apply physical wheel force.
- Corrected fresh-install free-play seeds, including Off Road's settings checksum.
  Existing player settings remain preserved.
- Restored missing release artwork/music, hardened installed updates and imports,
  and repaired frozen support diagnostics. Packages include required runtime
  files, source and licence texts.
- Added per-game experimental graphics and impact controls. Broad Margin Fill is
  retired because it smears sky detail. World terrain/scenery/distance options
  remain experimental and default off.

Known limits: scenery pop-in remains, particularly World's distant mountains and
trees. A larger far limit alone does not remove the game's delayed activation.
World may still need the experimental terrain option for some edge holes, and
extra guest drawing can change an older replay's route. The existing original
recordings remain preserved. Global distance experiments are World2.4-specific;
they are not a universal improvement for all four games.

Collision feel and Exotica wheel polarity still need attended checks across wheel
vendors. Similar strength percentages are not a guarantee of similar rim torque.
Telemetry coverage varies by game; the invalid RPM source has been removed.
The next release ships only after the exact candidate ZIP is accepted; a tag no
longer rebuilds and immediately publishes untested binaries.
