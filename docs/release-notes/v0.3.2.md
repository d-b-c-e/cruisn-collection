## Cruis'n Collection v0.3.2 — performance levers

Small follow-up for testers on lighter machines.

- **SETTINGS → INTERNAL SCALE** (2X / 3X / 4X): lower it if a game
  stutters; 4X is the sharpest. Applies at the next launch.
- **FFB STRENGTH 0%** now switches the force-feedback plugin fully idle -
  handy to check whether the plugin is what's slowing a game down.
- **If a game runs slow**: try INTERNAL SCALE 2X, FFB STRENGTH 0%, ASPECT
  4:3 and CRT off (F9) one at a time - whichever fixes it names the
  culprit - then `CruisnSetup → Save support bundle` right after the slow
  game (its log ends with the emulator's measured speed).

Update: close the launcher and unzip over your existing folder; everything
you set up is kept.
