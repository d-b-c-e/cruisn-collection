## Cruis'n Collection v0.3.4 — force feedback that survives exiting a game

- **FFB no longer dies after the first game of a session.** Reported on a
  Fanatec CSL DD: forces on the first launch, nothing after exiting, back
  only after running another emulator. Stopping leftover forces used to
  happen inside the launcher process itself; it now runs in a throwaway
  helper, and the wheel gets a clean open/close before every launch.
- The plugin author's **FFBReset** tool is included and runs for you at
  every exit and launch (the same tool a tester found fixes it by hand).
- Direct-drive wheels: INSTALL now says to start FFB STRENGTH at 40% on
  an 8 Nm base; 100% clips. Cruis'n Exotica has no force feedback at all
  (MAME does not emulate its wheel motor yet) - documented.
- An emulator process that hangs on exit is ended automatically, and any
  left-over one is ended before a launch.
- Support bundles now say whether an emulator process was still running.
- **Updates from inside the app**: `CruisnSetup.exe -> Updates...` (or
  SETTINGS -> CHECK FOR UPDATES in the launcher) finds the newer release,
  downloads it, closes the launcher, installs in place and reopens it.
  Nothing to set up.

Includes v0.3.3 (direct launch, Shift+F12, real steering sensitivity, old
ROM names). Update: close the launcher, unzip over your existing folder.
