# Cruis'n Collection v0.5.0

This alpha adds imported Cheats, live in-game activation and expanded Experiments
to Cruis'n USA, World, Off Road Challenge and Exotica.

- **Game card → Cheats** imports exact-revision MAME XML, ZIP or nested 7z files.
  Imports start off; no cheat database or ROMs are included.
- **Esc → Cheats** works in all four enhanced renderers. Change toggles and values,
  activate one-shots, then Resume to apply them. Instruction-restoring cheats can
  be enabled after the game has loaded and disabled through MAME's own interpreter.
  In-game changes apply to that session; they do not replace saved launch choices.
- Recorded drives retain live cheat actions at their actual emulated frames,
  including repeated one-shots. Replay is read-only and rejects altered evidence.
- **Settings → Experiments** now sits beside Display, with Shared and per-game
  contexts. Crack Fill remains a shared option with its existing default.
- World2.5 gains the optional global 2x/3x distance and +0/+8/+12 lookahead controls.
  Off Road gains its own 2x/3x distance experiment. Exotica's Widescreen Scenery
  experiment restores edge geometry; it does not extend the far plane.
- **Experiments → Exotica → Menu Force Feedback** optionally allows feedback in
  game menus and at race end. Off preserves suppression; changes take effect next
  launch. World feedback, Exotica polarity and the existing Exotica strength trim
  remain unchanged. Equivalent controls for other games are future work.
- Fix the normal-launch `cannot access local variable 'env'` error reported when
  launching with a cheat selected; it could also affect launches with cheats off.
- Separate local Release and Personal build targets keep personal calibration,
  bindings, display preferences and force profiles out of shipped defaults.
  Builds and checks run locally; publication uploads the exact tested ZIP.

Fresh installations use **CRT on, full widescreen, 4x rendering and free play**,
World2.4, 50% force and the CRISP profile. Per-game experiments and added impact
cues start off. Updates preserve saved preferences, which may differ from defaults.

## Known limitations

- Distance experiments do not eliminate pop-in. World New York can show black
  flashing and has a reported finish-line crash with 3x/+12; the cause remains
  unresolved. Keep distance experiments off for the baseline experience.
- World can oscillate in menus or at race end. Cross-game force normalization,
  impact feel and broader wheel testing remain open. Equal percentages do not
  guarantee identical forces across games or wheel bases.
- Imported cheat scripts retain their game-specific limitations. Automated checks
  cover timer behavior, available finish actions and instruction restoration;
  rank, nitro and every imported parameter/effect are not certified.
- Additional full manual-transmission drives, physical force checks, second-vendor
  coverage, clean Windows profile installation and a longer soak remain incomplete.
  The maintainer accepts the current alpha; unperformed checks remain documented
  as accepted limitations rather than new test passes.
- World speed telemetry still uses OCR. Gear and estimated RPM use guarded game
  signals; RPM is an arcade approximation, not a measured physical engine speed.
- Host scenery and some USA/Exotica distance work remain developer diagnostics.
  Their counters or higher limits do not establish correct occlusion or zero pop-in.
- The repository remains private. Downloads require access, and the anonymous
  in-app updater cannot discover private releases.

The previous v0.4.0 release remains available for rollback. This update does not
change repository visibility or bundle users' ROMs, cheats or personal settings.
