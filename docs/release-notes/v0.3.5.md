## Cruis'n Collection v0.3.5 — force feedback tuned for strong wheels

- **FFB STRENGTH works now.** It never reached the plugin's per-game
  force settings before, so the games always ran at 100% - which is a lot
  of why a strong wheel felt like it was clipping. Your saved percentage
  now really applies; start around 40% on a direct-drive base and tune up.
- The force-feedback plugin now runs in the mode this project's own rig
  was tuned in (earlier zips shipped the other mode).
- We measured what the games actually send to the wheel: a short kick
  against every wheel movement, not a centering spring. On a strong
  direct-drive base at 100% that becomes the wheel slamming left and
  right by itself - **start at 30-40% FFB STRENGTH** on an 8 Nm base and
  work up. INSTALL.md explains it under *Force feedback*.
- **Cruis'n Exotica gets force feedback** (experimental): the emulator
  now produces Exotica's wheel-motor signal, which no MAME build did
  before, and feeds it to the plugin through the same path as USA. Tell
  us how it feels.
- New **SETTINGS → FFB PEAK LIMIT**: caps those kicks (try 40) while the
  small road forces stay at full strength - lively wheel, no slamming.
- Support bundles' force traces can now be read with a small report tool
  that says whether the wheel was oscillating.

## Known issues

- **Cruis'n Exotica: manual transmission cannot be selected.** The
  TRANS SELECT screen always picks AUTO in MAME whatever you do - wheel,
  shifter, paddles or buttons. We mapped the operator menu and tested
  every input line and both cabinet settings; this is a gap in the
  upstream Exotica emulation (still marked not-working there), not a
  binding problem. Exotica drives as an automatic for now. The
  sequential-paddle shifter for it is already in place and will work
  the moment the game accepts manual.
- **Exotica graphical glitches (the Amazon track shows several) are in
  our GL overlay**: with `exotica_gl = 0` under `[collection]` in
  `rig\collection.ini` (MAME's own renderer, 4:3 native) they are gone.
  Use that switch if they bother you; the overlay fix is queued.
- The experimental draw-distance extension for USA is off (opt-in via
  `gamepatch_crusnusa`); a first look showed no visible change and it
  needs a measured comparison before it means anything.
- Fixed in this build: the launcher's settings save used to drop every
  config key it did not own (the FFB diagnostics flag among them) at
  each launch - support bundles made before this may lack the force
  trace for that reason.
- Exotica force feedback is new: report how it feels.
