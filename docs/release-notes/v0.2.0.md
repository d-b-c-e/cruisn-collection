## Cruis'n Collection v0.2.0

The big one since v0.1.0 — every facet we could improve on the originals.

**Headline: Off Road Challenge in true 16:9, both edges, drawn by the game itself.**
Off Road's own polygon culling ran on the game's DSP code, so 16:9 used to
show sky/water through the ground at the left edge. This release patches
that code in memory (ROM files are never touched): the right clip bound is
widened, and the left — which the game tested by sign bit with no bound to
widen — is mirrored by a tiny routine placed in unused padding. The 4:3
picture is pixel-identical; the margins are real geometry. As far as we
know this is the first game-code widescreen on Midway V-Unit hardware.

**Also new**
- **Cruis'n Exotica** now runs through our in-process GL renderer at 4×
  internal resolution with the CRT pass, in true full 16:9, with the
  upstream fixes for the black cars and the stuck post-race overlay.
- **In-game Esc menu** (Resume / CRT / Exit), F9 live CRT toggle.
- **Wheel setup wizard** handles >32-button wheels (Raw Input), axes,
  keyboard keys, and the Test/Service/Volume buttons.
- **Settings**: ASPECT presets (4:3 / TRIMMED / 16:9 FULL), MARGIN FILL,
  STEER CURVE, STEERING SENSITIVITY, FFB STRENGTH, CRT.
- **Telemetry for SimHub / motion rigs**: speed for USA and World, RPM for
  USA, HUD-OCR speed fallback, wheel force and lamps — as JSON UDP or as
  Forza Horizon "Data Out" packets (SimHub's stock Forza profile works).
- Per-game menu music with fades, support-bundle diagnostics, Cruis'n
  World's calibration screen gone for good, Off Road's last scanline back,
  pedal Auto/Manual self-select fixed.

**Install**: unzip, run `CruisnSetup.exe`, add your own ROM sets
(`crusnusa`, `crusnwld`, `offroadc`, `crusnexo` — MAME 0.286), launch.
No ROMs are included. Full details in `CHANGELOG.md` and `docs\INSTALL.md`.
