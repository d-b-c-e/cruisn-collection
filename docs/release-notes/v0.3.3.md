## Cruis'n Collection v0.3.3 — direct launch, quit-all key, old ROM names

- **Direct launch for frontends**: `CruisnCollection.exe --game usa`
  (or `world`, `offroad`, `exotica`) starts that game with your saved
  settings and no launcher screen; the process ends when the game does.
- **Shift+F12** while playing quits the game *and* the launcher - straight
  to the desktop. Plain F12 still just returns to the launcher.
- **Steering sensitivity works now.** The row used to set MAME's own
  analog "sensitivity", which has no effect on a wheel (MAME cancels it
  out for absolute controls). It is now a real gain: 100% = your in-game
  calibration, 150% = full lock with a third less turning, 70% = full
  travel gives 70% lock; the STEERING CURVE still shapes the response
  between center and lock. Values you set before are cleared. See
  "Steering feel" in INSTALL.md.
- **ROM names**: romsets from other MAME versions call the DSP boot-ROM
  sets `tms32031.zip` / `tms32032.zip` instead of `tms320c31` /
  `tms320c32`. Both are accepted now - add them through the setup window
  or just copy them in.

Includes v0.3.2 (INTERNAL SCALE setting, FFB STRENGTH 0% = plugin idle,
slow-game diagnostics). Update: close the launcher, unzip over your
existing folder - everything you set up is kept.
