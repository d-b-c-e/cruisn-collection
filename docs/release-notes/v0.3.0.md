## Cruis'n Collection v0.3.0 — alpha test build

First build meant for hands other than the author's. Unzip, run
`CruisnSetup.exe`, add your MAME 0.286 ROM zips (game sets plus the tiny
`tms320c31` / `tms320c32` DSP boot-ROM sets), launch — the full guide is
`docs\INSTALL.md` inside the zip. No ROMs are included.

**New since v0.2.0**
- **Cruis'n World manual transmission is back**: the World card boots rev
  2.4 (`crusnwld24`), the last revision with transmission select. Needs
  the `crusnwld24` files (merged set or `crusnwld24.zip`); otherwise the
  launcher falls back to 2.5 and tells you.
- **Per-game pages**: selecting a game opens PLAY plus that game's own
  settings — steering sensitivity/curve, volume and free play written
  straight into the game's own settings memory, and World's 2.4/2.5 switch.
- **TRANSMISSION setting**: H-pattern shifter or sequential paddles,
  chosen explicitly; CONTROLS SETUP asks only for the active style and
  both sets of bindings persist. Paddle rigs get the games' native
  sequential mode.
- **Wheel navigation**: after the wizard, the wheel steers the menus and
  the gas pedal confirms.
- **Setup GUI**: identifies ROM zips by content (any filename, merged or
  split sets), understands the World 2.4 clone, and a **support bundle**
  button for bug reports. Launch failures now show their reason on the
  menu instead of silently returning.
- **Rendering**: seam lines on 2D screens (USA continue map, Off Road
  track select) fixed at the source; 2D screens now measure closer to the
  arcade hardware than before. Smoked-glass translucency, World's full
  16:9 sky and terrain, no more launch "ding".

**Known issues (please report anything else)**
- Cruis'n Exotica: car-select stats text illegible, occasional sprite
  glitches — upstream MAME Zeus2 emulation.
- Force feedback needs your wheel's GUID in `FFBPlugin.ini` if the
  plugin doesn't pick it automatically (guide: "Force feedback").
- First launch may pause ~20 s before the game appears (FFB plugin device
  scan); it recovers by itself.
