## Cruis'n Collection v0.3.1 — force feedback fix

v0.3.0 shipped without the force-feedback hook (`dinput8.dll`) and with the
wrong plugin settings file, so a wheel steered but forces were missing or
came and went. This build ships the complete 64-bit FFB Arcade Plugin set
and a Cruis'n-tuned settings file.

**Updating from v0.3.0**: close the launcher and unzip this over your
existing folder (yes to overwrite) — ROMs, bindings, settings and
calibration are kept. Then run `CruisnSetup.exe → Detect wheel (FFB)` once
with the wheel base powered on (it remembers the wheel across future
updates). If you had copied in a `dinput8.dll` from elsewhere, the unzip
replaces it — nothing else to clean up.

**New**
- `CruisnSetup.exe → FFB diagnostics`: logs every force the game sends
  and everything the plugin does with it; save a support bundle after a
  minute of driving if forces still misbehave.
- `CruisnSetup.exe → Import previous version…` for updates into a new
  folder.

Everything else is v0.3.0 (see `CHANGELOG.md`).
