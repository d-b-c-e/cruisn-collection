# Earlier private visibility connected to original handover

The bounded Exotica experiment now makes future and waiting scenery reach its
normal completed appearance earlier, then carries that appearance into qualified
original draws. The Amazon sample visibly gains distant forest behind the
elephants. This establishes a useful rendering mechanism; it is not yet a smooth
appearance policy or release-ready four-game parity.

`--exotica-early-visibility endpoint` requires a separately frozen candidate,
private original-model replacement, actual draw admissions, lifetime observation,
and composed waiting/active margins. It cannot inherit activation from a recording.
The endpoint interval remains limited to120 frames. Guest memory, original command
execution, the normal render target and ordinary configurations are unchanged.

## Preserve the original overlap check

Completing alpha before comparing waiting and margin copies could hide an
original-state mismatch. The experiment retains the original waiting geometry,
filters original margin geometry against it, and only then selects corresponding
prepared endpoint quads. `exotica_scene_endpoint.h` requires exact instance order,
geometry/material identity and an exact ordered original subset. Rejection leaves
the output untouched. The source permission for a remaining margin object is
copied at CPU scene end with its owned operands, not borrowed from a later occupant
of its RAM slot. Independent Python folding checks those permissions against
actual lifetime and queued-packet watermarks.

Preparation deliberately runs original and endpoint margin assembly separately
inside the bounded experiment. This costs extra CPU time. It is diagnostic
validation, not a measured production performance improvement.

## A depth-state assumption corrected

The initial saved-scene test rejected a depth-state difference. Further inspection
found49 affected quads across the5072 and7187 samples. Their actual game flag0x200
completion restores register14=0x1000, disabling depth
writes as well as changing blend state. For example the5072 object flags are
0x04000330; the captured setup constants include0x40021e0e and0x14001000.
The permitted endpoint changes now include the depth-write bit. Depth testing,
vertices, texture/palette bindings and other state remain fixed. Completion still
requires the explicit0x04000000 marker; intrinsic transparency alone grants no
permission. The former narrower rule happened to fit the original-model samples.

Three actual original/completed scene pairs validate14,944 quads. Noncontiguous
subsets total7,184 quads and match independent byte selections exactly. Native
tests reject changed materials, depth tests, vertices, ordering and original alpha
mismatches, including changes in removed instances.
