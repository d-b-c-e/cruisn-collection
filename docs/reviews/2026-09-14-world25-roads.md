# World 2.5 extended roads — September 14, 2026

The diagnostic World road renderer now has a separately mapped 2.5 adapter.
This closes an implementation gap: 2.5 previously drew upcoming scenery while
excluding the extended road/ground path available in 2.4. The existing explicit
road switch is retained, with unchanged defaults and original guest simulation.

## Mapping and numerical checks

Saved original snapshots show the same road vertex and polygon codec in both
revisions. World 2.5 uses LOD threshold `D4BA` and selected-model state `D4B9`,
where 2.4 uses `D4C0` and `D4BF`. The template-table pointer remains at `624`.
The road allocation/setup code moves independently. Explicit instruction guards
cover each revision; no global address relocation is assumed. Unknown revisions
reject before memory access.

A new read-only 2.5 capture at frames 4400–4500 verifies 2,424 original road
calls: 672 near models and 1,752 far-template selections. All camera transforms,
matrices, projected vertex buffers and native template selections match an
independent reconstruction. All 2,227 unclipped ordered polygon batches match.
The 197 clipped calls have their projected vertices checked, but their clipped
polygon output remains outside this oracle. Unrelated polygon submissions are
counted separately and are not represented as road calls.

The 4,502-input probe replay preserves original native frames and all 2,701
camera samples plus 8,103 actual ADC reads/timestamps over its explicitly bounded
1800–4500 interval.

Untouched saved scene snapshots provide these independent full-geometry checks:

These totals count repeated objects across snapshots, not unique assets. The
2.5 samples include reset/menu state and partial loader frontiers. No already
allocated future descriptor or later allocation field mismatch was accepted.
Three native tests and seven Python tests pass, including revision-specific
thresholds, unsupported revisions, cache revision changes and frozen road choices.

Initial local qualification commands referenced an old draft's absent completion
summary and the wrong allocation-file directory. Those failures are retained;
the corrected four-snapshot 2.4 check is separate. The old draft is not claimed
as a newly completed canonical road-codec capture.

## Live comparison: small benefit, terrain gap remains

Two same-candidate 6,000-input replays with roads off/on preserve original native
frames, all 4,191 camera samples and 12,573 ADC reads/timestamps. The road-off
scene fingerprints exactly match the older accepted 2.5 3× baseline. The road-on
run processes 1,666 scenes, with 218,655 road-instance visits and 185,640 road
quads. Repeated visits are not unique objects.

Four of twelve completed images at 5400–5950 change by only 51–98 pixels each.
Visual inspection shows that the conspicuous disconnected distant terrain
remains; the adapter must not be described as fixing that defect. The large
nearby suspended road sign is also present in the older original-scenery control,
so it is not a new extended-road regression. The comparison closes support for
the road codec, while demonstrating that another mechanism limits useful fill
in this scene. Investigate distant LOD geometry and excluded custom allocation
before asserting that extra road submissions solve it.

MAME reports 100.00% average speed with roads off and 99.87% with roads on. The
completed captures are 3424×1353 on the current 3440×1440 monitor; no new final4K
or repeatability claim is made. `live-comparison.json` records expected image
differences separately from its passing input/motion comparisons. This is one
matched pair, not a new default-game regression suite.
