# Native Exotica waiting-cohort completion

The waiting-object reconciliation helper is now integrated into a separately
built native observer. Full Amazon and repeat runs preserve the original route,
resources and sampled displayed pixels. Every proposed cohort is reconciled at
the actual command fence, and all new observation files repeat exactly. This
establishes when an extra waiting copy must be omitted; extra waiting geometry
is **not drawn by this candidate**. Personal87d and public v0.5.0 are unchanged.

## Native behavior

Native `bc384056fd1e9cf4adf9ab6d8208bcc6d1da9463` is frozen at
`build/candidates/bc384056fd1/vunit.exe`, SHA256
`6b26731ee61a3a14c33acd2de63cd31334ed5e88e8bbf919205d00142f48ca9c`.
Its 187 exported patches reconstruct tree
`bc506377e0bbfc1d74b172bbb11e008e7587b2fe`.

Explicit `--exotica-host-handover observe` requires waiting observation, the
native lifecycle registry and the actual command-fence observer. Parent controls
require physical FFB off and the private future-scene experiment. The mode is
absent from normal launch defaults. It never switches the displayed target.

At proposal P, the helper derives the cohort from source descriptors and actual
registry ownership. It stores all owner handles in a bounded 64 MiB journal,
including source key, allocation slot, reset epoch and generation. At CPU scene
end E and actual device readiness R it records the **full native event-record
count**, rather than inferring it from timestamps or allocation counts alone.

The helper removes owners originally submitted, freed or reused since P. It
filters the already-built proposal geometry in source order and rebases instance
offsets. It does not rebuild against later WaveRAM, change fade/opacity, submit
another render packet or move the existing future packet. Reset, event-order,
ownership, scene and capacity guards remain enforced.

## Full-drive evidence

Both full runs preserve 8,860 inputs, 7,060 camera rows and 21,180 actual ADC
timestamps. Their 21 completed 3840x2160/CRT samples match the original displayed
target. All 6,953 existing future-scene fingerprints and the original sampled
RAM/Wave/context/geometry resources remain unchanged.

| Measurement | Full run and repeat |
|---|---:|
| Completed scene cohorts | 6,953 |
| Candidate visits captured | 1,021,808 |
| Visits removed after original submission | 2,621 |
| Visits removed by free/reuse | 0 |
| Retained candidate visits | 1,019,187 |
| Owner status changes from CPU end to device readiness | 0 |
| Full-cohort journal bytes | 49,324,904 |

These are cohort visits, not a million distinct scenery objects. The removed
visits are a subset of the earlier 2,692 total first-original-submission events
between proposal and CPU end; that older figure included non-cohort objects.

The canonical Python verifier independently folds the lifecycle journal at P/E/R
and checks every cohort's ownership, generation, status, counts and retained-order
hash. Five captured geometry samples also match independent prior Lua/Python
reconstruction, including the 155-to-145 owner change at5072. All 6,953 actual
watermark triples agree with the earlier timestamp-derived ledger. The earlier
short run separately passes 4,120 triples and nine geometry files.

All 17 new completion files repeat byte for byte: the cohort journal, scene CSV
and fifteen owner/instance/quad snapshots. The older lifetime/waiting/fence logs
and waiting snapshot files are unchanged. No new temporal fade, material-residency,
occlusion or performance acceptance is inferred from this observation result.

commands including GPU checks, source identity
`3c6991a18ba8cb689a5cb590d02d25125d4c3a7f999e25f3240b577cbab41d0d`.

The disabled full-drive control also passes the original route, future geometry
and 21 displayed images. It creates no waiting/completion artifacts, and its
lifetime journal matches the full observer exactly.

Next add an explicitly gated **private waiting draw**
at the established completion boundary, keeping future insertion early. Renew

opaque or treat equal depth as equal transparent composition. The existing left
