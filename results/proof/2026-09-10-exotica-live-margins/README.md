# Current-distance Exotica margin evidence

Run `python results/proof/2026-09-10-exotica-live-margins/verify.py` from the
repository root. No ROMs, emulator or GPU are needed for this archive verifier.

It recomputes published scene and copy counts, completion, ordered fingerprints,
initial full-copy requirements and source identity. It checks hash-bound receipts
for 397 completed 4K captures, full texture-image checks, original route/resources,
independent geometry, seven defaults and the final local suite. The 25-image
verification comparison intentionally differs from its no-draw control; equality
to the preceding drawing candidate is recorded separately.

Pixels, complete geometry, raw texture/RAM/model resources, native builds and
actual emulator tests are not rerun from this archive. Those results are receipts.
Initial failed trials remain explicitly failed. No far-distance, complete
occlusion, physical-force or deployment acceptance is claimed.
