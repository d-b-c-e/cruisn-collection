# Live original-only Zeus depth mirror

Run `python verify.py` in this directory. The verifier recomputes source identity,
frame coverage, counters, requested snapshot/writer coverage, repeat counters and
hash equality. It checks hash-bound receipts for GPU execution, raw buffer mapping,
displayed pixels, original route/resources, local checks and default coverage. Those
raw resources and images are not distributed here. Native compilation/export is
also a receipt; reconstruct the public patch against its stated base separately.

This accepts an original-only diagnostic, not farther drawing, material handover,
other drivers or normal-play performance. The displayed framebuffer is original.
Personal v0.5.0 is unchanged. The initial failures remain recorded. The full
seven-case suite has one USA widescreen timing failure (6.13seconds at1858);
the affected case passes a separate targeted retry. The other six cases pass.
This does not erase the original suite failure or resolve its stall cause.

The next-depth envelope and insertion samples describe existing captures only.
Farther geometry exceeds D24, and real fast clears use0xffff00. The proposed wider
clear policy and new geometry insertion are not integrated or accepted here.
