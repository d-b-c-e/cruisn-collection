# Exotica retained-material receipts

Run `python results/proof/2026-09-11-exotica-retained-materials/verify.py` to check
source hashes and aggregate consistency. The receipts cover a standalone compiled
material continuation on five previously accepted native completion snapshots,
independent Python packet bytes and one completed GPU-command comparison.

Full-image and retained-image waiting packets produce identical color and depth
at the same recorded insertion boundary, including a repeat. The earlier offline
future preparation used a different primitive order; the fresh comparison uses
actual native order. Both orders happen to give equal pixels in this sample.

The public verifier does not read private game bytes, execute MAME, rerun the
compiler or replay GPU commands. Those executions remain receipts. No live
waiting draw, new4K capture, fade/handover or speed acceptance is implied. The
personal/public build and current native executable are unchanged.
