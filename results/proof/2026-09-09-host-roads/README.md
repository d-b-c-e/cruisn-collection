# World host roads — publishable proof

Run `python verify_archive.py` with Pillow installed. No ROMs are needed.

The archive recomputes three complete driving input/camera/ADC traces, repeated
host fingerprints, two selected4K pixel comparisons, and seven telemetry/four
software-force verdicts. The repeated21-image result and full geometry/resource,
native numerical, build and GPU checks remain hash-bound receipts. It does not
rerender complete scenes or establish four-game parity.

The road decoder closes a missing uphill road section in Germany. Some adjacent
sky gaps remain. Failed timing, interrupted and display-transition trials are
retained. See the [review](../../../docs/reviews/2026-09-09-host-road-integration.md)
for candidate identity, acceptance limits and next adapter work.
