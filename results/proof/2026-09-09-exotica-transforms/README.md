# Exotica transform foundation evidence

Run `python results/proof/2026-09-09-exotica-transforms/verify_archive.py` with Pillow.
The verifier checks archive/source hashes and recomputes four original6000-input
prefixes,4191 camera samples/12573 actual analog addresses, values and timestamps,
and three selected3840x2160 images per run.

The full40093-transform/39541-emission verification, remaining21GL frames, native
analyzer execution, original Zeus resources and local native/GPU tests remain
hash-bound receipts. Their raw game operands are local and are not included here.
Initial special-matrix and frame-clock verifier failures are retained. The initial
native analyzer attempt lacked the MinGW DLL search path; the corrected run passes.

This is a standalone transform/LOD/cache foundation. It does not draw extra
Exotica scenery or establish Zeus model decoding, material residency, foreground
occlusion, handover or four-game3x acceptance. Personal v0.5.0 is unchanged.
