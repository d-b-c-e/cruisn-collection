# Off Road transform and future-source evidence

Run `python verify_archive.py` with Pillow installed.

The archive recomputes eight original input/camera/actual-ADC comparisons,
fifteen completed 3824x2073 image comparisons, and arithmetic checks for 1,978
scene frontiers in each of the two section probes. It retains failures and binds
the prepared-transform and final source/check inventories to their hashes.

Complete model/projection/DMA, ROM-table membership, object allocation/material
comparisons, and native/GPU executions remain **receipts**. The raw resources
needed to repeat those computations stay local. Scalar frontiers do not replace
actual ROM membership checks. The three headless runs have no GL acceptance.

This is standalone Off Road tooling, not native MAME host drawing or evidence
of visible 3x scenery. Material readiness/lifetime, clipping, scene ordering,
occlusion, handover and integrated performance remain open.

Source: collection `ccbfb56`; native candidate `cf58c40632c` is unchanged.
See [the review](../../../docs/reviews/2026-09-09-offroad-future-sections.md).
