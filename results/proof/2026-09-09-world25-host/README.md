# World 2.5 host-scenery evidence

Run `python verify_archive.py` from this directory or by absolute path. Requires
Pillow; ROMs and game resource dumps are unnecessary.

The archive recomputes equality of five6000-frame input/time traces, camera and
actual ADC timestamps, the declared common interval against the earlier longer
trace,350 observed reset-state scenes, repeated3x scene fingerprints, three
selected4K image pairs, and seven telemetry/four software force checks.
It also recomputes the USA model probe's3552-input/1751-camera/5253-ADC equality
against its control. The5178 projection/44652-DMA numerical verdict is a receipt;
its raw model operands remain local. This is an adapter prototype, not host drawing.

Full geometry/resource equality, the remaining completed GL images, snapshot
math/descriptor oracles and native/GPU builds are hash-bound receipts. Raw ROMs,
model buffers, textures and code snapshots stay local. Earlier failed guards,
incomplete probes and reference checks remain explicit.

The3x mode adds visible scenery over2x, but disconnected distant terrain remains.
This evidence does not certify whole-track quality, road decoding, material
lifetime, physical FFB or four-game parity. Stream Deck remains on v0.5.0.
