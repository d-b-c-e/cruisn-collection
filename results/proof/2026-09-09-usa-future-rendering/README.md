# USA future rendering evidence

Run `python verify_archive.py` with Python and Pillow. The archive contains
publishable traces, selected rendered gameplay images, source hashes and receipts.
Raw ROMs, model/material dumps and complete geometry streams remain local.

The verifier recomputes 17 original input/camera/ADC comparisons, complete repeated
host counters/fingerprints, four selected 4K image windows, the recorded timing
limits and seven telemetry/four software force verdicts. Other images, full scene
oracles, resource equality, native builds and GPU fixtures remain hash-bound
receipts. Verification does not turn those receipts into independently rerun tests.

USA 3x now adds small visible changes over2x on this recording. It still runs below
full speed despite caching improvements. Broader material lifetime, upload/partial
transitions, sky, occlusion and handover remain open. This is not release approval
or a claim of comparable 3x rendering across all four games.
