# Exotica CPU visibility proof

Run `python verify_archive.py`. The archive contains the complete339,018-sample
read-only trace, frozen probe/analyzer, original input-frame evidence and runtime
receipts. It recomputes every sphere-test result without ROMs. The21 completed
3840×2160 GL matches are bound receipts; full BMPs remain local.

The corrected acceptance tap is after the final delayed branch. A failed sample
from the earlier tap is retained as a negative control. A replay PASS alone did
not validate that first probe's interpretation.

Predicted additional CPU admissions do not establish visible scenery or an
accepted renderer change. No emulator binary, ROM or original INP is included.
