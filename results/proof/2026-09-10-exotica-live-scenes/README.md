# Exotica live scene observer evidence

Run `python results/proof/2026-09-10-exotica-live-scenes/verify.py` from the repository.

These33 receipts bind the local checks, separate native build/export, three
paired6000 replays, original motion/resources/4K images, independent scene/geometry
verification, repeated full observer fingerprints, and a standalone bounds draft.
The verifier recomputes receipt and source-identity hashes and checks their
declared consistency. It **does not** rerun MAME, execute the native analyzer or
recompute unarchived geometry, resources, motion or pixels.

Raw RAM, ROM, WaveRAM, CPU journals, generated geometry and screenshots remain
local under `results/diagnostics/exotica-amazon-20260909`. Failures are retained
there and identified by hashes here. The observer does not draw extra scenery;
the bounds draft is not linked into MAME. Seven-default renewal is separate.

See the [review](../../../docs/reviews/2026-09-10-exotica-live-scenes.md) for scope,
failures, measured cost and remaining work. No deployment or release occurred.
