# Off Road model codec evidence

This archive accompanies collection `dc04e6b` and
[the review](../../../docs/reviews/2026-09-09-offroad-model-codec.md).
Run `python results/proof/2026-09-09-offroad-model-codec/verify_archive.py`
with Pillow installed.

The verifier recomputes seven complete original input/motion comparisons and all
twelve completed3824x2073 GL images from four visible runs. It checks the captured
camera and actual ADC timestamps, archive hashes and348-file source identity.
It also checks the integrity of the failed initial assumptions and the final
local suite/codec receipts.

The1,399 projection/9,602 ordered-DMA comparisons and463/3,309 repeat are **receipts**:
their private model/ROM/material inputs are intentionally absent. Native/GPU
execution reports are also receipts, not rerun by the archive verifier. There is
no host renderer, prepared-transform/LOD-selection, material lifetime, clipping,
occlusion, handover or extended-distance acceptance claim here. No MAME binary or
personal deployment changed; cf58 retains its earlier seven-default qualification.
